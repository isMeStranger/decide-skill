# Bias and fallacy scan — name only the ones actually present, give the fix

Evidence note: anchoring and gain/loss framing replicated strongly (Many Labs 1, 2014). Many Labs 2 replicated only 15 of 28 classic effects. Ego depletion ("willpower runs out") failed a multi-lab replication — do not use it. Debiasing works best with **structure** (checklists, premortems, outside view, independent scoring), not by "being aware".

## Biases (judgment errors)

| Bias | Sign in the conversation | Fix |
|---|---|---|
| Confirmation | Only reasons for the favourite; no search for disconfirming facts | "What would change your mind?" Search for it. Red-team the runner-up. |
| Overconfidence | Narrow ranges, "definitely" | Ask for a 90% range; widen it. Use base rates. |
| Planning fallacy | "Will take 2 months" | Reference class: how long did similar projects take? Add the typical overrun. |
| Anchoring | First number mentioned drives the estimate | Estimate before seeing the number; use several independent anchors. |
| Availability | Recent/vivid story drives probability | Ask for the base rate, not the story. |
| Sunk cost | "I've already put so much in" | Only future costs and benefits count. "Would I start this today?" |
| Loss aversion / status quo | Staying put just because change feels risky | Reverse test: "If you were already in option B, would you switch to A?" |
| Framing | Answer flips between "90% survive" and "10% die" | Restate the choice both ways. |
| Endowment | Overvaluing what you own | "What would you pay to buy it now?" |
| Halo | One great trait makes everything look great | Score criteria independently (MAP). |
| Optimism / wishful thinking | Best case treated as likely | Premortem; write worst and median cases. |
| Hindsight / resulting | Judging past decisions by outcome | Ask what was knowable then. |
| Narrow framing | Only one decision considered in isolation | Widen: what else could the money/time do (opportunity cost)? |
| Present bias | Short-term comfort beats long-term good | 10/10/10; commitment devices. |
| Social proof / herd | "Everyone's doing it" | Do their reasons apply to you? Check base rate of outcomes. |
| Authority | "Expert X says" | Check track record and incentives of the expert. |
| Scarcity / urgency | "Offer ends today" | Is the deadline real? Who benefits from your hurry? |
| Survivorship | Learning only from winners | Ask how many tried and failed. |
| Base-rate neglect | Specific story ignores how often it happens | Start from the base rate, then adjust (Bayes). |
| Escalation of commitment | Doubling down after bad news | Pre-set tripwires and kill criteria. |
| Affect heuristic | Liking it → believes risk is low | Assess risk and benefit separately. |
| Groupthink | Fast agreement, no dissent | Independent written views before discussion; assign a devil's advocate. |
| Noise | Same facts, different answer depending on mood/time | Structured scoring; decide twice at different times and average. |

## Fallacies (reasoning errors in the arguments)

| Fallacy | Example | Check |
|---|---|---|
| False dilemma | "Either quit or stay miserable" | Add options (Step 2). |
| Sunk cost | see above | Future-only. |
| Slippery slope | "If I take this, I'll never get out" | Probability of each step? |
| Appeal to popularity | "Most people choose X" | Relevant to my goals? |
| Appeal to authority | "My uncle says" | Expertise in this exact area + incentives? |
| Gambler's fallacy | "I've failed 3 times, so next must work" | Independent events don't owe you. |
| Hot-hand / small sample | "Worked twice, so it works" | Sample size. |
| Post hoc | "I did X then Y happened, so X caused Y" | Other causes? Control comparison? |
| Ad hominem | "She's wrong because she's young" | Judge the argument. |
| Straw man | Weakened version of the other option | Steelman it. |
| Nirvana fallacy | Rejecting an option because it's not perfect | Compare to the real alternatives. |
| Correlation ≠ causation | "People with MBAs earn more" | Selection effect? |
| Appeal to nature / tradition | "It's always been done this way" | Does the reason still hold? |
